# ScorePulse showcase site

A one-page Vite site (plain HTML, CSS and a tiny script). No framework.

- Run it: `npm install`, then `npm run dev`. Build: `npm run build` (output in `dist/`).
- **The download link** is `public/config.json` (`downloadUrl`). Empty shows "coming soon". Change it and redeploy the
  site; no app update is needed.
- **Screenshots** are `public/shots/*.png`, taken from the web build of the app with the local dev sign-in. They show
  placeholder/demo data. Retake them from a phone build before launch.
- **Deploy on Vercel:** import the repo, set Root Directory to `site`, framework Vite, build `npm run build`, output `dist`.
